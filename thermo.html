1. Systems, Properties & Quasi-static Process

⏱ 45 min 🏆 2–3 marks 🔗 Prereq: None

📝 Theory Notes

  • Macroscopic approach: studies the average behaviour of a large number of molecules — no molecular model needed; uses properties like P, V, T, m. Simpler, used in classical thermodynamics. (MO2024 P1 Q.1(a), MO2025 MID Q.1(a))
  • Microscopic approach: studies the behaviour of individual molecules statistically (statistical thermodynamics); uses velocity, kinetic energy, mean free path, momentum.
Property typeDefinitionExamples
IntensiveIndependent of massPressure, density, temperature, specific volume
ExtensiveDepends on mass (additive)Mass, volume, energy, enthalpy (H = m·h), potential energy
MO2022 END Q.1(a): Classify density / potential energy / enthalpy / pressure — the trick is enthalpy (H) is extensive, while specific enthalpy (h) is intensive.
  • Quasi-static process (MO2024 P2 Q.1(a), MO2025 MID Q.2(a)): proceeds infinitely slowly through a continuous sequence of equilibrium states; system is always in equilibrium with surroundings; path is fully defined → work can be computed as ∫P dV. Characteristic features: infinitely slow, reversible idealization, system at equilibrium at every instant.
  • Thermodynamic equilibrium (MO2024 P1 Q.2(a)): mechanical (no unbalanced forces) + thermal (no temperature difference) + chemical equilibrium (no composition change). Thermal equilibrium alone only requires uniform temperature.

2. Work, Heat & Point/Path Functions

⏱ 30 min 🏆 2–3 marks

📝 Theory Notes

  • Work (thermo definition, MO2023 Q.1(a)): energy transfer that crosses the system boundary due to a difference in an external generalized force (pressure × volume change for a gas). It is a boundary phenomenon and appears at the boundary.
  • Heat: energy transfer due solely to temperature difference between system and surroundings.
  • Point functions (MO2025 MID Q.3(a)): depend only on state — P, V, T, u, h, s. Exact differentials: ∫dP = ΔP.
  • Path functions: depend on how the process happens — work W and heat Q. Inexact differentials: δW, δQ; ∫δW = W, not a difference.
Free expansion (MO2023 Q.1(b)): unrestrained expansion into vacuum — no work done (no resisting force), no heat transfer for ideal gas, final temperature unchanged for ideal gas (u depends only on T).

📘 Worked Example

MO2025 MID Q.1(b): Balloon sphere D = 1 m, air at 200 kPa/300 K, heated till pressure 500 kPa. Find work.

Balloon: P ∝ r (surface tension / elasticity) → P = c·r Work W = ∫P dV ; V = 4πr³/3, dV = 4πr² dr P = P₁(r/r₁), r₁ = 0.5 m W = ∫₀.₅^r₂ P₁(r/r₁)·4πr² dr = (P₁/r₁)·π r⁴ |₀.₅^r₂ P₂/P₁ = r₂/r₁ → r₂ = 0.5×(500/200) = 1.25 m W = (200×10³/0.5)·π·(1.25⁴ − 0.5⁴)/… → evaluate → W ≈ 580 kJ

3. First Law of Thermodynamics & Internal Energy

⏱ 45 min 🏆 2–5 marks 🔗 Prereq: Topic 2

📝 Theory Notes

For a process: Q = ΔU + W (closed system, KE/PE neglected) For a cycle: ∮δQ = ∮δW → net heat = net work
  • Internal energy (MO2024 P1 Q.4(a)): sum of molecular kinetic + potential energies; a property because its change is path-independent — proved via cyclic integral ∮du = 0 (if it were path-dependent, a cycle could create energy from nothing).
  • Enthalpy (MO2025 MID Q.4(a)): h = u + Pv (kJ/kg). Used for constant-pressure processes: Q = m(h₂ − h₁).
  • Specific heats: c_v = (∂u/∂T)_v, c_p = (∂h/∂T)_p; for ideal gas c_p − c_v = R; γ = c_p/c_v.
  • Ideal gas: PV = mRT; u = u(T) only.
MO2022 END Q.1(b): rigid tank 1 m³ (100 kPa, 300 K) + tank 0.5 m³ (250 kPa, 400 K) mix to 315 K → final pressure: m₁ = P₁V₁/RT₁ etc., P_f = (m₁+m₂)RT_f/V_total. Final volume = 1.5 m³.

4. Polytropic Process

⏱ 45 min 🏆 3–5 marks 🔗 Prereq: Topic 3

📝 Theory Notes

PVⁿ = constant (n = polytropic index) Work done: W = (P₁V₁ − P₂V₂)/(n − 1) = mR(T₁ − T₂)/(n − 1) Heat transfer: Q = m·c_n·(T₂ − T₁) ; c_n = c_v·(γ − n)/(1 − n) Relation: T₂/T₁ = (P₂/P₁)^((n−1)/n) = (V₁/V₂)^(n−1)

MO2023 Q.4(b): Prove ∫δQ = ((γ − n)/(γ − 1)) × polytropic work:

δQ = dU + δW = mc_v dT + δW δW = (P₁V₁ − P₂V₂)/(n−1) ; dT = T₂ − T₁ = (P₂V₂ − P₁V₁)/mR Q = mc_v(P₂V₂ − P₁V₁)/(mR) + W = c_v(P₂V₂ − P₁V₁)/R + W = [(P₂V₂ − P₁V₁)/(γ−1)] + [(P₁V₁ − P₂V₂)/(n−1)] = W·(γ−n)/(γ−1) ∎
nProcess
0Constant pressure (isobaric)
1Isothermal (PV = const)
γIsentropic / adiabatic reversible
∞Constant volume (isochoric)

📘 Worked Example

MO2022 END Q.2(b): 1 kg air, 7 bar, 90 °C, PV^1.1 = const, falls to 1.4 bar. Find T₂, V₂, heat transferred.

T₂ = T₁(P₂/P₁)^((n−1)/n) = 363×(1.4/7)^(0.1/1.1) = 363×(0.2)^0.0909 ≈ 363×0.863 = 313.3 K V₁ = mRT₁/P₁ = 287×363/(7×10⁵) = 0.1488 m³ V₂ = V₁(P₁/P₂)^(1/n) = 0.1488×5^(0.909) ≈ 0.1488×4.31 = 0.641 m³ c_n = c_v(γ−n)/(1−n) ; c_v = 0.718, γ = 1.4 → c_n = 0.718×0.3/(−0.1) = −2.154 Q = 1×(−2.154)×(313.3−363) = +107 kJ

MO2024 P2 Q.2(a): derive heat transfer in polytropic process (same result as above — the standard 3-marker).

5. Steady Flow Energy Equation (SFEE) & Nozzles

⏱ 60 min 🏆 3–5 marks 🔗 Prereq: Topic 3

📝 Theory Notes

Q̇ − Ẇ = ṁ[(h₂ − h₁) + (V₂² − V₁²)/2 + g(z₂ − z₁)]

Derivation (MO2024 P1 Q.5(a)): energy balance on a control volume between two sections — enthalpy flux in/out + KE + PE + heat + shaft work = 0 under steady state (dm/dt = 0, dE/dt = 0).

Applications (MO2025 END Q.2(a))

DeviceAssumptionsResult
NozzleAdiabatic, no work, Δz ≈ 0h₁ + V₁²/2 = h₂ + V₂²/2 → V₂ = √[2(h₁ − h₂) + V₁²]
Throttling valveAdiabatic, no work, KE≈PE≈0h₁ = h₂ (isenthalpic)
TurbineAdiabatic, ΔKE, ΔPE ≈ 0Ẇ = ṁ(h₁ − h₂)
CompressorAdiabatic, ΔKE, ΔPE ≈ 0Ẇ_in = ṁ(h₂ − h₁)
Nozzle numericals appear in almost every paper: MO2022 END Q.2(c), MO2023 Q.5, MO2024 P2 Q.2(b), MO2025 MID Q.5(b).

📘 Worked Example

MO2025 MID Q.5(b): Dry saturated steam 5 bar enters adiabatic nozzle at 2 m/s, leaves as dry saturated steam at 2 bar. Find exit velocity.

From steam tables: h₁(5 bar dry) = 2748 kJ/kg, h₂(2 bar dry) = 2707 kJ/kg V₂²/2 = (h₁ − h₂) + V₁²/2 = 41,000 + 2 J/kg (in J/kg: 41 kJ/kg = 41,000 J/kg) V₂ = √(2×41002) ≈ 286.4 m/s

MO2022 END Q.2(c): steam 3 MPa/320 °C → 1.6 MPa at 550 m/s, ṁ = 0.5 kg/s → h₂ = h₁ − V₂²/2, then check superheated table to find condition at exit.

6. Steam Properties, Tables & Throttling

⏱ 45 min 🏆 3 marks 🔗 Prereq: Topic 5

📝 Theory Notes

  • Pure substance (MO2024 P1 Q.3(a)): same chemical composition in all phases. Air is not a pure substance in the phase sense (mixture of gases with different condensation points) — although treated as one for most problems.
  • Quality x: mass fraction of vapour in wet steam. h = h_f + x·h_fg; v = v_f + x·v_fg; s = s_f + x·s_fg.
  • Throttling is isenthalpic (h₁ = h₂) — used for measuring wetness fraction and for MO2025 MID Q.3(b) "show h_i = h_e".

📘 Worked Example

MO2023 Q.3(b): Heat to convert 2 kg water at 25 °C to steam at 5 bar, 0.9 dry.

At 5 bar: h_f = 640 kJ/kg, h_fg = 2108 kJ/kg h₂ = 640 + 0.9×2108 = 2537 kJ/kg Q = m(h₂ − h_f,25°C) = 2×(2537 − 104.9) = 4864 kJ

MO2023 Q.3(a): water at P = 0.5 MPa, h = 2890 kJ/kg → at 0.5 MPa h_f = 640.2, h_g = 2748 → h > h_g → superheated → look up superheated table at 0.5 MPa near 2890 → T ≈ 400 °C.

MO2025 END Q.1(b): 0.8 kg steam at 300 °C, 1 MPa cooled at constant pressure until half the mass condenses → x = 0.5 at exit; final T = saturation temp at 1 MPa = 179.9 °C; show on T-v diagram.

7. Second Law & Carnot Cycle

⏱ 45 min 🏆 5 marks 🔗 Prereq: None

📝 Theory Notes

  • Kelvin–Planck: impossible for a heat engine to produce net work while exchanging heat with a single reservoir. (No perfect engine.)
  • Clausius: impossible to transfer heat from a colder to a hotter body without external work. (No perfect refrigerator.)
  • Equivalence (MO2025 END Q.3(a)): violation of one ⇒ violation of the other — prove by coupling the violator with a reversible machine to construct the forbidden device.
Carnot efficiency: η = 1 − T_L/T_H (T in kelvin) COP_ref = T_L/(T_H − T_L) ; COP_hp = T_H/(T_H − T_L) = COP_ref + 1

Carnot theorem (MO2022 END Q.3(b)): no heat engine operating between two reservoirs can be more efficient than a reversible engine between the same reservoirs; all reversible engines have equal efficiency.

Absolute temperature scale (MO2024 P2 Q.3(b)): Φ(t) = at + b; Q₁/Q₂ = Φ(T₁)/Φ(T₂). With 20 kJ at 100 °C and 14.6 kJ rejected at 0 °C: 20/14.6 = (a·373+b)/(a·273+b) → solve with Q→0 at absolute zero → locate 0 °C position on the Celsius scale → T_abs0 ≈ −273 °C.

📘 Worked Example

MO2022 END Q.3(c): Ice plant on reversed Carnot: 20 tonnes ice/day from 0 °C water, rejected to atmosphere at 27 °C.

Q_L = 20,000 kg × 335 kJ/kg = 6.7 GJ/day (latent heat of fusion) COP = T_L/(T_H − T_L) = 273/(300 − 273) = 10.11 W = Q_L/COP = 6.7×10⁹/(10.11×86400 s) = 7.67 kW Q_H = Q_L + W (heat rejected to atmosphere)

8. Heat Pump vs Refrigerator

⏱ 20 min 🏆 2–3 marks 🔗 Prereq: Topic 7

📝 Theory Notes

  • Both transfer heat from cold to hot using work input — same machine, different purpose.
  • Refrigerator: purpose is to extract heat from the cold space (Q_L). COP_R = Q_L/W = T_L/(T_H − T_L).
  • Heat pump: purpose is to supply heat to the warm space (Q_H). COP_HP = Q_H/W = T_H/(T_H − T_L) = COP_R + 1.
  • COP_HP is always > 1 — heat pumps are attractive heating devices.
MO2022 END Q.3(a) & MO2024 P2 Q.3(a): "Define and compare COP of heat pump with that of refrigerator" — a 2–3 mark guaranteed question.

9. Entropy, Clausius Inequality & Availability

⏱ 60 min 🏆 5 marks 🔗 Prereq: Topic 7

📝 Theory Notes

Clausius inequality: ∮δQ/T ≤ 0 (= 0 reversible, < 0 irreversible) Entropy change: dS = δQ_rev/T (property — independent of path) ΔS for constant-T reservoir: ΔS = Q/T ΔS for constant-P heating: ΔS = m·c_p·ln(T₂/T₁) ΔS for constant-V heating: ΔS = m·c_v·ln(T₂/T₁) ΔS for ideal gas: ΔS = m[c_v ln(T₂/T₁) + R ln(V₂/V₁)]
  • Entropy as a property (MO2022 END Q.4(a)): ∮dS = 0 for any cycle → S is a point function → property.
  • Entropy principle (MO2022 END Q.4(b)): entropy of the universe (isolated system) always increases: ΔS_univ ≥ 0.

Available / unavailable energy (MO2025 END Q.4(b))

Available energy of heat Q at T with environment T₀: A = Q(1 − T₀/T) (maximum useful work from a reversible engine) Unavailable energy: Q·T₀/T

Clausius–Clapeyron (MO2025 END Q.5(a))

dp/dT = h_fg / (T·v_fg) → slope of the liquid–vapour boundary dp/dT = s_fg/v_fg = h_fg/(T·v_fg)

Joule–Thomson coefficient (MO2025 END Q.5(b))

μ_JT = (∂T/∂P)_h → > 0 cooling on expansion, < 0 heating, 0 at inversion temperature

📘 Worked Example

MO2022 END Q.4(c): Copper block 600 g, C_p = 150 J/K at 100 °C placed in lake at 8 °C. Find ΔS_universe.

Block: ΔS_block = m·c·ln(T₂/T₁) = 150×ln(281/373) = 150×(−0.283) = −42.4 J/K Heat to lake: Q = 150×(373−281) = 13,800 J Lake: ΔS_lake = Q/T_lake = 13800/281 = +49.1 J/K ΔS_universe = −42.4 + 49.1 = +6.7 J/K > 0 ✓ (irreversible)

MO2025 END Q.4(b): 0.2 kg air at 300 °C heated reversibly at constant pressure to 2066 K, T₀ = 30 °C.

Q = m·c_p·(T₂−T₁) = 0.2×1.0047×(2066−573) = 299.9 kJ ΔS = m·c_p·ln(T₂/T₁) = 0.2×1.0047×ln(2066/573) = 0.2581 kJ/K Unavailable = T₀ΔS = 303×0.2581 = 78.2 kJ Available = Q − 78.2 = 221.7 kJ

10. Otto & Diesel Cycles

⏱ 45 min 🏆 5 marks 🔗 Prereq: Topic 4

📝 Theory Notes

Otto cycle (constant volume heat addition): η_Otto = 1 − 1/r^(γ−1) where r = V₁/V₂ (compression ratio) Diesel cycle (constant pressure heat addition): η_Diesel = 1 − [1/(r^(γ−1))]·[(ρ^γ − 1)/(γ(ρ − 1))] where ρ = V₃/V₂ (cut-off ratio)
  • Air-standard assumptions: air as ideal gas, c_p, c_v constant, all processes internally reversible, no intake/exhaust, fixed mass.
  • Otto derivation (MO2024 P2 Q.5(a)): Q_s = c_v(T₃−T₂), Q_r = c_v(T₄−T₁), η = 1 − Q_r/Q_s = 1 − (T₄−T₁)/(T₃−T₂); with T₄/T₁ = (V₁/V₂)^(γ−1) = r^(γ−1) = T₃/T₂ → η = 1 − 1/r^(γ−1).
  • Diesel derivation (MO2022 END Q.5(a)): heat added at constant pressure Q_s = c_p(T₃−T₂), rejected at constant volume → same algebra with the cut-off ratio.

📘 Worked Example

MO2024 P2 Q.5(b): Otto cycle, r = 7, start 35 °C, 0.1 MPa, max T = 1100 °C.

State 2: T₂ = T₁·r^(γ−1) = 308×7^0.4 = 308×2.178 = 670.9 K P₂ = P₁·r^γ = 0.1×7^1.4 = 0.1×15.25 = 1.525 MPa State 3: T₃ = 1373 K, V₃ = V₂ → P₃ = P₂·T₃/T₂ = 1.525×1373/670.9 = 3.12 MPa State 4: T₄ = T₃/r^(γ−1) = 1373/2.178 = 630.4 K P₄ = P₁·T₄/T₁ = 0.1×630.4/308 = 0.205 MPa η = 1 − 1/7^0.4 = 1 − 0.459 = 54.1%

⚡ Quick Revision Cheat Sheet

Must-Know Formulas

Q = ΔU + W (process) ; ∮δQ = ∮δW (cycle)
h = u + Pv ; c_p − c_v = R ; γ = c_p/c_v
W_poly = mR(T₁−T₂)/(n−1)
Q_poly = W·(γ−n)/(γ−1)
SFEE: Q̇−Ẇ = ṁ[Δh + ΔV²/2 + gΔz]
V₂ = √[2(h₁−h₂) + V₁²] (nozzle)
η_carnot = 1 − T_L/T_H
COP_R = T_L/(T_H−T_L) ; COP_HP = COP_R + 1
∮δQ/T ≤ 0 ; dS = δQ_rev/T
η_Otto = 1 − 1/r^(γ−1)
η_Diesel = 1 − [ρ^γ−1]/[r^(γ−1)·γ(ρ−1)]
Available = Q(1 − T₀/T)

Common Traps

  • Enthalpy H is extensive; specific enthalpy h is intensive.
  • Free expansion: W = 0, Q = 0, ideal gas T unchanged.
  • Work and heat are path functions (δW, δQ); always in J not J/kg unless specified.
  • Use kelvin in all entropy, efficiency and Carnot calculations.
  • Throttling: h₁ = h₂ (isenthalpic) — not isothermal.
  • COP_HP = COP_R + 1 — always larger.
  • Entropy of universe ≥ 0 for all real processes.
  • Polytropic: n = γ → adiabatic; n = 1 → isothermal (use special formulas for isothermal W = P₁V₁ ln(V₂/V₁)).
