1. Bisection, Regula-Falsi, Secant & Newton-Raphson

⏱ 90 min🔗 Prereq: None

📝 Theory Notes

Big idea: computers cannot solve f(x) = 0 directly — every method here just narrows a bracket or slides downhill using repeated guesses. The differences are speed vs safety.
  • Error vocabulary: round-off error (finite digits), truncation error (cutting an infinite process), absolute error $E_a=|x_{true}-x_{approx}|$, relative error $E_r=E_a/|x_{true}|$. Errors propagate: for $z=x+y$ errors add; for products/quotients relative errors add.
  • Bisection: needs a sign change f(a)f(b) < 0; halve the interval each step, keep the half that still changes sign. Always converges, linearly slow: error halves per step.
  • Regula-falsi (false position): same bracketing safety but joins (a,f(a))-(b,f(b)) with a straight line and uses its root as the next point — usually faster than bisection.
  • Secant: same line-idea but without needing a sign bracket — uses two latest points. Superlinear (order ≈ 1.62), but can wander off.
  • Newton-Raphson: slide down the tangent at the current guess:
$x_{i+1}=x_i-\dfrac{f(x_i)}{f'(x_i)}$ — quadratic convergence: correct digits roughly double each step. Fails when f' ≈ 0 (flat), poor initial guess, or multiple roots. General iterative form: $x=g(x)$ fixed-point iteration converges iff $|g'(x)|<1$ near the root.

📖 Exam Definitions — quote these in your answers

  • Truncation error: The error caused by replacing an infinite mathematical process with a finite number of steps (e.g. stopping a Taylor series early).
  • Round-off error: The error introduced because numbers are stored with a finite number of significant digits.
  • Order of convergence: How fast successive errors shrink: if e(k+1) ≈ C·e(k)^p, p is the order (bisection p = 1, secant p ≈ 1.618, Newton-Raphson p = 2).
  • Bisection method: A bracketing root-finding method which repeatedly halves an interval containing a sign change; guaranteed to converge.
  • Newton-Raphson method: An open iterative method that follows the tangent line at the current estimate to find the next, converging quadratically near a simple root.

📘 Worked Example

Solve x³ − 2x − 5 = 0 by Newton-Raphson from x₀ = 2: f(x) = x³−2x−5, f'(x)=3x²−2 $x_1 = 2 - \dfrac{8-4-5}{12-2} = 2.1$ $x_2 = 2.1 - \dfrac{9.261-4.2-5}{13.23-2} = 2.0946$ $x_3 = 2.0946 - \dfrac{0.0055}{11.16} \approx \mathbf{2.09455}$ ✓ (digits doubling as promised)

2. Gaussian Elimination, LU Decomposition & Iterative Methods

⏱ 75 min🔗 Prereq: None

📝 Theory Notes

Big idea: two philosophies — eliminate variables directly (exact up to round-off, finite steps) or iterate from a guess (cheap per step for huge sparse systems, must converge).
  • Gaussian elimination: forward elimination to upper-triangular form using row operations (pivot = divide by diagonal), then back-substitution. Cost ≈ n³/3 multiplications.
  • Gauss-Jordan: keep eliminating above AND below pivots → identity matrix; right side becomes the answer. No back-substitution needed, ~50 % more work.
  • LU (Crout/Doolittle): factor A = LU once, then solve LUX = b via two cheap triangular solves — perfect when many b's share one A. Partial pivoting (swap rows for biggest pivot) controls round-off.
Jacobi update: $$x_i^{(k+1)}=\dfrac{1}{a_{ii}}\Big[b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\Big]$$ (all old values) Gauss-Seidel: same formula but use NEWEST available values → converges ~2× faster. Convergence guaranteed if A is diagonally dominant: $|a_{ii}|>\sum_{j\ne i}|a_{ij}|$.

📖 Exam Definitions — quote these in your answers

  • Pivoting: Interchanging equations (rows) during elimination so the pivot element is the largest available in magnitude, minimising round-off amplification.
  • LU decomposition: Writing A = LU where L is lower- and U upper-triangular, allowing repeated solutions for different right-hand sides with only two triangular solves.
  • Gauss-Seidel method: An iterative solution scheme that immediately uses updated component values within the same sweep, converging under diagonal dominance.
  • Diagonal dominance: Property |aii| ≥ Σ|aij| (j ≠ i) for every row, strictly somewhere — a sufficient condition for convergence of Jacobi/Gauss-Seidel iterations.

📘 Worked Example

Solve x + y = 3, 2x − y = 0 by Gauss-Seidel from (0, 0): From eq1: x = 3 − y → x₁ = 3 From eq2: y = 2x − y_old? no — y = 2x exactly: y₁ = 2(3) − 0 = ... use rearranged y = 2x: y₁ = 6?? check: 2(3) − 6 = 0 ✓ Iterate: x₂ = 3 − 6 = −3, y₂ = −6; x₃ = 9, y₃ = 18 — DIVERGES! Rows are NOT diagonally dominant (row2: |−1| < 2). Swap equation order: now x from eq(2x−y=0): x = y/2 → x₁ = 0; y = 3 − x → y₁ = 3; x₂ = 1.5, y₂ = 1.5; x₃ = 0.75...→ converging to (1, 2) ✓ Lesson: equation ORDER decides convergence — reorder for dominance.

3. Lagrange & Newton's Difference Formulas

⏱ 60 min🔗 Prereq: None

📝 Theory Notes

Big idea: interpolation draws the unique polynomial through your data points and reads between them. Equal spacing? Newton's forward/backward saves work. Uneven spacing? Lagrange or divided differences.
  • Lagrange (unequal spacing friendly):
$P(x)=\sum_{k} y_k\prod_{j\ne k}\dfrac{x-x_j}{x_k-x_j}$ — no table needed, weights built straight from nodes.
  • Divided differences: build a triangle: first column f[x_i,x_j] = (f_j−f_i)/(x_j−x_i); higher columns repeat on shorter intervals. Top entries become coefficients of Newton's divided-difference polynomial.
  • Equal spacing shortcuts: define Δ (forward) and ∇ (backward) differences; then:
Newton forward (near top): $P(x_0+hu)=y_0+u\Delta y_0+\dfrac{u(u-1)}{2!}\Delta^2y_0+\dfrac{u(u-1)(u-2)}{3!}\Delta^3y_0+\cdots$ Newton backward (near bottom): replace u→v measured from last node with ∇ differences.
  • Choosing: interpolate close to the START → forward; close to END → backward; middle → central/Stirling (beyond scope) or fit divided difference.

📖 Exam Definitions — quote these in your answers

  • Interpolation: Estimating the value of a function between known tabulated points using a polynomial fitted through those points.
  • Shift operator Δ: Δy(x) = y(x+h); repeated application builds the forward-difference table used in Newton's formulas.
  • Divided difference: The coefficient f[x₀,…,xₖ] defined recursively as (f[x₁,…,xₖ] − f[x₀,…,xₖ₋₁])/(xₖ − x₀), symmetric in its arguments.
  • Lagrange interpolation: Direct construction of the interpolating polynomial as a weighted sum of node-specific basis polynomials, valid for unequal spacing.

📘 Worked Example

Points (1, 1), (2, 8), (3, 27) — estimate f(2.5) by Lagrange: $P=\dfrac{(2.5-2)(2.5-3)}{(1-2)(1-3)}(1)+\dfrac{(2.5-1)(2.5-3)}{(2-1)(2-3)}(8)+\dfrac{(2.5-1)(2.5-2)}{(3-1)(3-2)}(27)$ = 0.125(1) + 0.75(8) + 0.125·? recompute third weight: (1.5×0.5)/2 = 0.375 → 0.375×27 = 10.125 Total = 0.125 + 6 + 10.125 = $\mathbf{16.25}$ — exact, since data came from x³ and P is cubic-degree ≤ 2? (16.25 vs true 15.625 shows quadratic fit limitation — good discussion point.)

4. Differentiation & Integration — Newton-Cotes Rules

⏱ 60 min🔗 Prereq: Topic 3

📝 Theory Notes

Big idea: integration numerically = replace the curve with easy shapes (straight lines or parabolas) and add their areas. Fewer assumptions than calculus, controlled by step size h.
  • Differentiation from tables: differentiate the Newton forward polynomial instead of the function:
$f'(x_0)=\dfrac{1}{h}\Big[\Delta y_0-\tfrac{1}{2}\Delta^2y_0+\tfrac{1}{3}\Delta^3y_0-\cdots\Big]$ — derivative at a tabular point.
  • Trapezoidal rule: join points with straight lines (works with ANY number of intervals):
$I\approx\dfrac{h}{2}\big[y_0+2(y_1+y_2+\cdots+y_{n-1})+y_n\big]$, $h=\dfrac{b-a}{n}$ Error $\propto h^{2}$ · exact for straight lines only.
  • Simpson's 1/3: pass parabolas through triplets of points — n must be EVEN:
  • Simpson's 3/8: cubics through quads — n must be a multiple of 3:
$I\approx\dfrac{h}{3}\big[y_0+4(y_{odd})+2(y_{even,\,interior})+y_n\big]$ · error $\propto h^{4}$ · exact up to cubic. $I\approx\dfrac{3h}{8}\big[y_0+3(y_1{+}y_2)+2y_3+3(y_4{+}y_5)+2y_6+\cdots+y_n\big]$
  • Picking a rule: Simpson 1/3 is the default exam choice (check even intervals!); trapezoidal when intervals are odd or data noisy; Richardson/Romberg = combine two h values to kill leading error term (extra credit).

📖 Exam Definitions — quote these in your answers

  • Newton-Cotes formulas: A family of integration rules that replace f(x) between equally-spaced nodes by an interpolating polynomial of degree n and integrate that exactly.
  • Trapezoidal rule: Newton-Cotes rule with n = 1 — area under straight chords connecting consecutive data points.
  • Simpson's one-third rule: Newton-Cotes rule with n = 2 — integrates quadratic interpolants exactly; requires an even number of equal intervals.
  • Degree of precision: The highest polynomial degree a quadrature rule integrates exactly (trapezoidal: 1; Simpson 1/3: 3).

📘 Worked Example

Evaluate $I=\int_0^1\dfrac{dx}{1+x^2}$ (exact π/4 = 0.785398) with h = 0.25: y values: 1, 0.9412, 0.8, 0.6400, 0.5 Trapezoid: $\frac{0.25}{2}[1+2(0.9412+0.8+0.64)+0.5]=0.125\times6.2624=\mathbf{0.7828}$ Simpson 1/3: $\frac{0.25}{3}[1+4(0.9412+0.64)+2(0.8)+0.5]$ $=\frac{0.25}{3}[1+6.3248+1.6+0.5]=\frac{2.3549}{3}\times?$ compute: sum=9.4248×0.08333=\mathbf{0.7854}$ ✓ matches π/4 to 4 decimals.

5. Solving y' = f(x, y) — Euler to Runge-Kutta 4

⏱ 75 min🔗 Prereq: Topic 4

📝 Theory Notes

Big idea: march forward in small steps h: at each point ask "which way is the solution heading?" (slope) and step there. Better methods just ask the slope more cleverly before committing.
  • Euler's method: follow the tangent blindly — cheap, order 1, drifts badly unless h tiny:
  • Modified Euler (Heun): predict with Euler, correct using the average of start/end slopes — order 2 predictor-corrector:
Euler: $y_{n+1}=y_n+h\,f(x_n,y_n)$ Heun: $\tilde y=y_n+h f(x_n,y_n)$ then $y_{n+1}=y_n+\dfrac{h}{2}\big[f(x_n,y_n)+f(x_{n+1},\tilde y)\big]$ RK2 (general midpoint form): $y_{n+1}=y_n+k_2$ with $k_1=hf(x_n,y_n)$, $k_2=hf(x_n+\tfrac{h}{2},y_n+\tfrac{k_1}{2})$ Runge-Kutta 4 (the workhorse, order 4): $$k_1=hf(x_n,y_n)\quad k_2=hf\!\big(x_n+\tfrac{h}{2},y_n+\tfrac{k_1}{2}\big)$$ $$k_3=hf\!\big(x_n+\tfrac{h}{2},y_n+\tfrac{k_2}{2}\big)\quad k_4=hf(x_n+h,y_n+k_3)$$ $$y_{n+1}=y_n+\tfrac{1}{6}(k_1+2k_2+2k_3+k_4)$$ RK4 needs no derivatives beyond f itself and no starting values — why it beats multi-step methods in coursework.

📖 Exam Definitions — quote these in your answers

  • Initial-value problem: An ODE together with enough starting conditions y(x₀) = y₀ to pin down a unique solution, solved by marching forward in x.
  • Euler's method: First-order single-step method advancing along the tangent at each point: y(n+1) = yn + h·f(xn, yn).
  • Predictor-corrector: A scheme that first estimates (predicts) the next value with one formula, then refines it (corrects) using another, e.g. modified Euler.
  • Runge-Kutta method: A single-step method built from several weighted slope evaluations inside each step, achieving high order without higher derivatives; RK4 has fourth-order accuracy.
  • Local truncation error: Error committed in a single step assuming previous values were exact; global error accumulates these over the interval.

📘 Worked Example

dy/dx = y, y(0) = 1, h = 0.1 — compare methods at x = 0.1 (true e^0.1 = 1.105171): Euler: y₁ = 1 + 0.1(1) = \mathbf{1.100000} (error 5.2e-3) Modified Euler: ŷ = 1.1; y₁ = 1 + 0.05(1 + 1.1) = \mathbf{1.105000} (error 1.7e-4) RK4: k₁=0.1, k₂=k₃=hf(0.05, 1.05)=0.105, k₄=hf(0.1, 1.105)=0.1105 y₁ = 1 + (1/6)[0.1+2(0.105)+2(0.105)+0.1105] = 1 + (1/6)(0.6305) = \mathbf{1.105083} (error 8.8e-5 at half the Heun cost per order — RK4 earns its reputation)
